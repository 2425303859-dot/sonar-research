## 当前能确认的内容

代码提供数据读取、预处理、网格标签编码、极简 CNN、训练、框解码与 NMS、评价及绘图流程。

已有报告的输入路径是 data/synthetic_sctd/Annotations，代码在缺少真实数据时会生成合成图像。因此当前保存的结果属于合成数据上的入门演示，不是已经完成的真实 SCTD 论文复现，也不是 SCTD2 U-Net 分割项目。

## 运行入口与配置

原代码头部给出的运行入口：

    python sonar_detection_sctd.py

依赖包括 torch、numpy、Pillow、matplotlib。先在单独环境配置依赖；运行前检查 CONFIG 中的 data_root 和 out_dir，输出目录避免覆盖已归档实验。

原代码配置包含：输入 256 × 256、检测网格 8 × 8、batch size 8、学习率 3e-3、随机种子 2026。具体参数以链接中的固定版本为准。
