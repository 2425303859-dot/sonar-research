# GitHub 每周更新指南

## 写论文笔记

仓库页面选择 Add file → Create new file，文件名填写 papers/年份-方法名.md。复制 [论文模板](../templates/paper-note.md)，填写后点击 Commit changes 保存。

## 上传代码与结果

在对应目录使用 Add file → Upload files 上传。持续写代码时可用 GitHub Desktop 同步本地项目。原作者代码应保留来源与许可证。

每次实验保存独立目录，例如 results/unet/exp-001/，包含说明、配置、日志、指标和图片。原始数据和大权重以获取方式或下载链接记录。

## 更新周报和首页

复制 [周报模板](../templates/weekly-report.md)，以日期命名；在首页增加笔记链接，更新项目状态和最新周报入口。状态区分初读、精读、推理跑通、训练中、评估完成。

## 在 Markdown 中显示结果图

把图片与实验说明一起上传后，在说明中写：

    ![预测结果](prediction.png)

图片路径相对于当前文档；使用 Preview 检查显示效果。

## 避免覆盖实验

先复制配置、记录版本，再运行。每次实验使用新输出目录，保留旧结果。提交信息写具体内容，例如“记录 U-Net 基线实验及失败案例”。

## 汇报前检查

- 阅读数量与复现数量分别统计。
- 报告中的每个结果都有数据类型、配置和文件依据。
- 辅助笔记已由本人核对；自己的理解和候选问题分别标注。
- 所有链接可打开，老师从首页能找到本周内容。
